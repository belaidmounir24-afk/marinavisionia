Bienvenue sur Marina Visionnaire

Guide pratique pour la navigation côtière en Méditerranée, l'activation du Mode Premium, la gestion des points GPS (data_points.json) et l'édition sur Android (Acode / Spck Editor).

Ouvrir l'application Voir data_points.json

1. Démarrer en Mode Invité & Activer le Mode Premium

  1. Ouvrez l'application sur votre téléphone Android ou navigateur. Par défaut, l'interface s'ouvre en Mode Invité (compas, carte sonar et GPS de base gratuits).
  2. Si vous avez reçu un code d'accès temporaire (format MV-XXXX-XX), rendez-vous sur l'onglet Bento dans la carte Abonnement & AISStream.
  3. Saisissez votre code puis appuyez sur Activer : le passage en Mode Premium et le déverrouillage d'AISStream s'effectuent automatiquement.

2. Enregistrer vos Coordonnées GPS & Points d'Intérêt

  • Capture GPS 1-clic : appuyez sur Enregistrer ma position pour capturer vos coordonnées sans saisie manuelle.
  • Saisie manuelle ou JSON : chaque point enregistré respecte le format modulaire data_points.json (nom, region, lat, lon, note) et reste mémorisé dans visionia_memoire. 
{
  "nom": "Île Srigina",
  "region": "Golfe de Skikda",
  "lat": 36.9355,
  "lon": 6.8902,
  "note": "Phare et passe nord-ouest, fond rocheux 18-32 m"
}

3. Installation PWA sur Android (Mode Hors-Ligne)

  1. Ouvrez Marina Visionnaire dans Google Chrome sur Android.
  2. Appuyez sur le bouton Installer l'app ou sur le menu ⋮ → Ajouter à l'écran d'accueil.
  3. Le Service Worker conserve la carte et vos repères accessibles même sans réseau en mer.

4. Édition Modulaire sur Android (Acode / Spck Editor)

Si vous travaillez depuis un dossier décompressé sur Android avec Acode ou Spck Editor :

  • data_points.json : ajoutez ou modifiez vos points GPS (nom, region, lat, lon, note).
  • assets/guide.html : mettez à jour ce guide client à tout moment sans toucher au code principal.
  • genererMotDePasse() & genererCodeAcces() : fonctions cryptographiques Web Crypto prêtes à l'emploi dans le contrôleur JS.
